# Glossary

## Purpose

This document defines the common business terms used throughout LeadFlow AI.

The glossary ensures that every team member uses the same terminology when discussing the product.

---

# Organization

A business using LeadFlow AI.

Every resource belongs to an Organization.

---

# Owner

The highest-level user within an Organization.

Responsible for billing, settings, and overall management.

---

# User

A member of an Organization.

Examples

- Admin
- Sales Manager
- Sales Agent

---

# Role

Defines what a user can do inside the platform.

---

# Permission

A specific action a user is allowed to perform.

Example

Create Lead

Delete Lead

Invite User

---

# Lead

A potential customer who has shown interest in a product or service.

A Lead is the most important business object in the system.

---

# Lead Source

The origin of a Lead.

Examples

- Website
- Facebook
- WhatsApp
- Manual Entry
- Import

---

# Pipeline

A visual representation of the sales process.

---

# Stage

A step inside a Pipeline.

Example

New

Contacted

Qualified

Site Visit

Negotiation

Won

Lost

---

# Activity

A record of an important action performed in the system.

Examples

- Lead Created
- Lead Assigned
- Stage Changed
- Task Completed

Activities cannot be edited.

---

# Timeline

The chronological history of a Lead.

Contains all Activities related to that Lead.

---

# Task

A follow-up action assigned to a user.

---

# Note

Additional information recorded against a Lead.

---

# Form

A customizable form used to collect lead information.

---

# Field

A single input inside a Form.

Examples

- Name
- Email
- Phone
- Budget

---

# Submission

Data submitted through a Form.

---

# Website

A website connected to LeadFlow AI that hosts public forms.

---

# Conversation

A communication thread between a customer and the organization.

---

# Message

A single communication inside a Conversation.

---

# Channel

The platform through which communication occurs.

Examples

- WhatsApp
- Facebook
- Website
- Email

---

# Integration

A connection between LeadFlow AI and an external service.

Examples

- Facebook Lead Ads
- WhatsApp Business
- Google Calendar

---

# Notification

A message generated by the system to inform users about important events.

---

# Dashboard

The main overview screen displaying business metrics and summaries.

---

# Report

A collection of business statistics used for analysis.

---

# Subscription

The customer's active pricing plan.

---

# Tenant

An Organization within the multi-tenant architecture.

Every Organization is an independent tenant.

---

# Multi-Tenant

A software architecture where multiple organizations use the same application while keeping their data completely isolated.

---

# MVP

Minimum Viable Product.

The smallest version of the product that provides real value to customers.

---

# Domain Event

An important business event that occurs within the system.

Examples

- Lead Created
- Lead Assigned
- User Invited

These events may trigger notifications, automation, or integrations.

---

# RBAC

Role-Based Access Control.

A security model where permissions are assigned to roles instead of individual users.

# Identity

A global user account used to authenticate into LeadFlow AI.

Membership

The relationship between a User and an Organization.

Role

A collection of permissions defined within an Organization.

Permission

A globally defined business action provided by the platform.
